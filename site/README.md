# cyrinx.org

Static site for the Cyrinx acoustic-modem research project. The checked-in
source has no build step, framework, or authored client-side JavaScript. It
uses plain HTML/CSS and self-hosted IBM Plex WOFF2 subsets. Cloudflare currently
injects its Web Analytics beacon into production HTML responses on the custom
domain; that runtime script is not present in this directory.

## Local preview

```bash
.venv/bin/python -m http.server -d site 8080
# open http://localhost:8080
```

## Deploy

The production site is a Cloudflare Pages project named `cyrinx`:

```bash
wrangler pages deploy site --project-name cyrinx --branch main
```

The repository and site may be connected in the Cloudflare dashboard instead;
use `site` as the output directory and no build command. `_headers` carries the
cache and security headers.

## Assets

- `assets/og-card.png` and `assets/apple-touch-icon.png` are generated by
  `.venv/bin/python scripts/gen-site-assets.py`. The social card is retained as
  a source asset but is not currently referenced by page metadata.
- `cyrinx-acoustic-link.pdf` is the Cyrinx 1.0 paper and
  `cyrinx-2-goodput.pdf` is the Cyrinx 2.0 follow-on. Both are copies of the
  compiled PDFs under `docs/whitepaper/`; recopy them when their sources change.
- `fonts/` contains latin WOFF2 subsets of IBM Plex under the Open Font License.

## Publication status

The repository, v2.0.0 release, and site are public. Changes under `site/` do
not reach production until an authenticated Cloudflare deployment completes.
